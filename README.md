# borghese-instagram-media

Imágenes públicas para el Instagram de [@borgheseperformance](https://www.instagram.com/borgheseperformance/).

Cada carpeta es una semana ISO (`AAAA-Www`) y solo contiene piezas aprobadas. Instagram las toma desde
`https://raw.githubusercontent.com/b0rghi7404/borghese-instagram-media/main/<semana>/<archivo>.jpg`.

Las fuentes editables y el calendario de publicación están en el repositorio privado de Borghese Performance.
